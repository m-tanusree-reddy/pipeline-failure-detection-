Pipeline Architecture

Explore the modular, agent-driven architecture that powers CI Debug Agent. From log ingestion to intelligent root-cause analysis.

cloud_done GitHub Actions
The entry point. Webhooks trigger the agent when a workflow run fails.
reorder Log Parser
Normalizes heterogeneous log formats into a structured JSON stream.
category Classifier
Uses heuristic patterns to identify if the failure is infra, test, or code-related.
psychology Planner Agent
Orchestrates the debugging strategy based on the initial classification.
inventory_2 Collector
Fetches relevant codebase context, previous PRs, and similar failures.
content_cut Chunker
Breaks down massive log files and source files into semantic chunks.
database FAISS Vector DB
Indexes embeddings for high-speed similarity search across millions of logs.
AI
auto_awesome Gemini LLM
The core reasoning engine. Analyzes the failure context to generate root causes.
gavel Critic Agent
Validates the LLM output against real-world constraints to prevent hallucinations.
summarize Report Generator
Final output stage. Creates a rich debugging report with code snippets and fix suggestions.

bolt Real-time Intelligence

Unlike traditional log aggregation tools, our architecture is built around an Agentic Loop. Instead of just showing you the error, the system actively queries your repository context, looks up similar failures in historical data, and iterates on potential fixes before you even open the dashboard.
